# CGG Academic English

These rules come from a reviewer's written comments on English research text and are generalized to any
paper, thesis, or summary. The full list is in [rules](references/rules.md). Sentence-level polish belongs to
[natural-expression](../natural-expression/SKILL.md); the user's latest explicit decision wins over
everything.

Write for a careful reader outside the field. They judge whether the text tells one story and whether it
reads easily, so the introduction and the conclusion matter most.

## 1. Fix the story before writing prose

For the introduction and the conclusion, write one sentence per paragraph first and check it against
[story and structure](references/rules.md#a-story-and-structure). Agree on that outline with the user before
rewriting full paragraphs.

Done when the outline answers: what current technology lacks, why these problems, what they share, what the
work claims, and how each contribution tests the claim.

## 2. Apply the rules by area

| Area | Covers |
|---|---|
| A. Story and structure | top-down motivation, one topic in one place, related-work placement, one claim |
| B. Readability | distant references, consistent names, terms defined before use, consequences |
| C. Background and figures | self-contained background, a figure for the main contribution, meaningful diagrams |
| D. Claims and evidence | claims matching results, accurate description of the evaluation |
| E. Conclusion | what was achieved, labelled limitations, long-term outlook |
| F. Figures, tables, wording | caption placement and content, standard terms |

Done when each edited paragraph satisfies the rules of every area it touches.

## 3. Report

List the rules applied and any rule that conflicts with a decision the user made, so the user can choose.
