# Report Template

```markdown
## Bugs (lanes A, B, D; verified)

| # | file:line | issue | lane | status | proof path |
|---|---|---|---|---|---|

Unverified or below the top 8: short list.

## End-to-End and Hygiene (lane D, non-bug items)

Dependencies, process, tests, and security notes not already in the bug table.

## Design (lane C)

Ranked topics, then "If you do only three things".

## Coverage

Files each lane opened versus files in the target; anything no lane read. State that the review was static
and name the findings whose proof path was not run.
```
