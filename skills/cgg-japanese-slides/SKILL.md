# CGG Japanese Slides

This skill holds only rules that a reviewer wrote down while marking several rounds of a Japanese
thesis-review deck; the full list is in [rules](references/rules.md).
General workflow, storyline, and speaker scripts belong to [academic-slides](../academic-slides/SKILL.md);
sentence polish belongs to [japanese-expression](../japanese-expression/SKILL.md). Where they overlap on
Japanese slides, the rules here win; the user's latest explicit decision wins over everything.

Judge every page by one question: can a reviewer from another field, possibly older and sitting at the back,
understand in a few seconds what this page says and where to look?

## 1. Check the basics before asking for review

The reviewer's sharpest complaint was a first draft, made with AI, that ignored comments given many times
before. Using AI is fine; checking it is the author's job. Before handing a deck to anyone, run the
[checklist](references/checklist.md) on the exported PDF, and when a comment arrives, apply it to every page
with the same habit, not only the marked one.

Done when every checklist item has been checked on the exported pages.

## 2. Apply the rules by area

Read [rules](references/rules.md) for the area being edited:

| Area | Covers |
|---|---|
| A. Text size and amount | 20pt floor, one or two lines, line breaks |
| B. Page structure | message line, title match, subject, page order and logic |
| C. Layout and whitespace | annotations on the figure, edges, bottom margin, alignment |
| D. Figures | concept figures, arrows, rays, cameras, zoom insets, sample images |
| E. Tables and numbers | ↑↓, units, captions, highlights with on-screen text |
| F. Citations | 図の出典, no citations on own figures |
| G. Japanese notation and wording | 体言止め, half-width symbols, standard terms |
| H. Animation | reveal order, one element per explanation |
| I. Cover, ending, and delivery | title page, publication list, outlook, speaking |

Done when each edited page satisfies the rules of every area it touches.

## 3. Report

List which rules were applied, which pages changed, and any rule that conflicts with a project decision, so
the user can choose.
