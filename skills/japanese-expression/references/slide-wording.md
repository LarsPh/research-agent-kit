# Slide Wording

Conventions for Japanese slide text and speaker notes, from the user's own review rounds. Notation that a
lab standard already fixes (体言止め, half-width symbols, spaces) lives in
[cgg-japanese-slides](../../cgg-japanese-slides/references/rules.md).

## Sentences

- A bullet is one sentence; do not split it with 「。」 into fragments.
- Use 「、」 rather than て for parallel actions (頭部を入れ替え、体型を合わせる).
- Keep task names, the method's approach, and categories of prior work as three separate vocabularies.
- A term coined by a paper or by the presenter is defined on screen at first use or replaced by a plain
  description; an English term is fine when clearer (full, w/o). A name that hides what it does gets the
  action spelled out (「画像誤差順の基底選択」, not 「画像誤差順」).
- After writing new Japanese, scan for literal carry-overs from Chinese and check meaning against the paper.

## Carry-overs and dated words

| Avoid | Use |
|---|---|
| 要求 | 要件 |
| 人体の知識 | 人体構造の知識 |
| 外観データ | 外観情報 |
| 学習組 | 学習ペア |
| 補正器 | 補正モデル |
| 融合 (features) | 統合 |
| 拡大 (resolution) | 高解像度化 |
| 接続 (systems) | 統合 |
| 中立 | 基準 |
| 計算機 | デジタル、コンピュータ |
| 崩れ | 破綻 |
| そろえる | 揃える |
| 〜台 (cameras) | 〜視点 |

## Readings in speaker notes

- Add a reading at the first occurrence per page of hard kanji and acronyms: `破綻（はたん）`,
  `VTON360（ブイトン サンロクマル）`.
- For words with okurigana, put the okurigana before the bracket: `覆う（おおう）`, `補え（おぎなえ）ます`,
  `囲ん（かこん）だ`.
- Choose readings by context: 上 is じょう in レイ上 / メッシュ上 and うえ in 表の上.
- If a rendered script or pitch-accent page exists, confirm every reading actually appears there; tools
  often drop hints on okurigana words.
