# Eval Results, 2026-11-01

Six fresh agents (same model), one per scenario × {with skill, without skill}. Fixtures were generated with numpy;
each run worked on its own copy.

| Scenario | Without skill | With skill |
|---|---|---|
| 1 Mirrored motion | Found the X mirror (residual 0), body-frame cross-product evidence, guard check | Same cause; also fitted mirror vs 180° yaw vs label swap and compared residuals; diagnostic sheet; thresholds set first. Reported that `rotation` on stored matrices passes (S·R·S, det +1) |
| 2 Unfair 3DGS comparison | Refused to call B worse; similarity fit, 0.009 mean error; floaters found | Same verdict; normalised with opacity filter, 48 orientation candidates incl. mirrors, IoU 0.946 / F-score 0.998 with thresholds set before looking; diagnostic sheet + orientation grid |
| 3 NeRF loader BGR + half-flipped pose | Both bugs found and fixed, PSNR 11.94 → 23.65 | Both found and fixed, same PSNR; det = −1 on all loaded poses via the script; before/after sheet; listed edge speckle as unresolved |

Finding: all six runs found the true causes, so these fixtures do not separate the two conditions on correctness.
The skill changed the process: pre-set thresholds, a fixed diagnostic sheet, explicit alternative hypotheses,
mirror candidates, and an "unresolved" list. Harder fixtures (several interacting bugs, renders without labels,
time budget) are needed to measure accuracy gains.

Change made from the runs: the rotation check misses mirrors stored as S·R·S; added `handedness` to the script
and to invariants.md, symptom-table.md, and SKILL.md step 5.
